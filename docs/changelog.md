# 更新日志

## v0.0.1-beta3（预览版）

发布日期：2026-10-21

- ✨️ 新增首页与托盘活动提醒入口、贪睡统计、数据目录迁移、历史保留策略和未使用铃声清理，批量删除支持整批回滚。
- 🐛 修复响铃窗口收起后反复弹出、编辑倒计时重置、远期单次提醒和重复提醒日期筛选问题；历史保留触发时分类，编辑离开前确认未保存内容。
- 🐛 更新检测同时支持稳定版与预览版，兼容 beta 数字排序；完善下载进度、失败重试和安装包目录入口，切换页面后保留下载状态。
- 🎨 优化首页、设置和表单的内容宽度适配及大字体布局，跨年日期显示年份，完善字段错误聚焦与历史状态图标。
- ⚡️ 完善一致性备份、恢复时活动提醒取消、数据迁移和清理恢复验证，新增回归测试并通过严格静态检查。

这是预览版本。升级前请从“设置 → 备份”导出重要数据；遇到问题请通过 GitHub Issues 反馈。

- ⚡️ 补充状态映射与历史筛选边界验证，完善代码静态检查。

这是预览版本。升级前请从“设置 → 备份”导出重要数据；遇到问题请通过 GitHub Issues 反馈。

## v0.0.1-beta1（预览版）

发布日期：2026-10-17

- ✨️ 支持单次、重复与倒计时提醒；重复规则覆盖每天、每周、每月、每季度和每年，并可设置生效日期范围。
- ✨️ 提醒到期时显示系统通知和响铃窗口；提醒、分组、标签及提醒历史保存在本地 SQLite，并支持历史筛选与分页。
- ✨️ 支持每日自动备份并保留最近 7 份备份，托盘菜单可快速创建 10 或 30 分钟倒计时。
- 🐛 修正重复提醒的月底与 31 号规则，并改善响铃窗口关闭时对并行提醒的处理。
- 🎨 改进提醒表单、列表、设置和分组/标签管理界面。

这是预览版本。首次使用或升级前，请先从“设置 → 备份”导出重要数据；遇到问题请通过 GitHub Issues 反馈。
