# 更新日志

## v0.0.1-beta6（预览版）

发布日期：2026-10-22

- ✨️ Windows 安装版支持“更新并重启”：下载校验后自动备份数据、安装到原目录并重新打开应用；未保存的编辑先确认，安装失败可直接重试。
- 🎨 多时间点提醒突出下一次时间，卡片以时间标签和弹出列表展示完整安排，表格支持点击查看全部时间点并标记下一次提醒。
- 🐛 修复卡片内容换行导致高度与底栏不一致的问题，优化窄窗口和大字体下的时间展示。
- 🎨 统一提醒编辑页标签栏、表单与保存栏宽度，缩小多余缩进并保留底部间隔；移除侧栏顶部重复的品牌区域。
- 🐛 取消手动检查更新的冷却倒计时，可随时重新检查；保留自动检查缓存及更新源限流退避。

> 测试版，请先备份重要文档；遇到问题请通过 Issues 反馈。

## v0.0.1-beta5（预览版）

发布日期：2026-10-22

- ✨️ 更新检查优先读取官网静态清单，分别记录稳定版与预览版；仅在安装包全部上传且校验信息齐全后公布新版本。
- 🐛 增加本地检查缓存、每 6 小时自动检查和手动检查冷却；网络失败保留上次结果与检查时间，避免误报最新版本。
- 🐛 GitHub API 仅作有限备用，遇到限流遵循服务端等待时间并显示友好提示；关于页提供“前往发布页”入口。
- 🔧 安装包下载完成后校验 SHA-256，校验失败丢弃临时文件；补充更新源切换、限流退避、缓存和发布清单回归测试。

这是预览版本。升级前请从“设置 → 备份”导出重要数据；遇到问题请通过 GitHub Issues 反馈。

## v0.0.1-beta4（预览版）

发布日期：2026-10-22

- ✨️ 重复提醒支持多个自定义时间，以及每半小时、1 小时和 2 小时间隔；支持跳过首次时间点，临近 5 分钟时默认勾选并提供说明。
- 🐛 Windows 首次启动自动在安装目录初始化本地数据，无需先选目录；保留已有自选目录，macOS 自动使用包外用户数据目录。
- 🐛 倒计时的下一次提醒预览每秒刷新，无需操作页面；完善多时间提醒的排序、跨天和首次跳过规则。
- 🎨 批量管理栏新增“退出管理”，数据设置新增“打开本地目录”；关于页显示当前版本标签、新版本与更新内容，检查更新使用主按钮样式。

这是预览版本。升级前请从“设置 → 备份”导出重要数据；遇到问题请通过 GitHub Issues 反馈。

## v0.0.1-beta1（预览版）

发布日期：2026-10-17

- ✨️ 支持单次、重复与倒计时提醒；重复规则覆盖每天、每周、每月、每季度和每年，并可设置生效日期范围。
- ✨️ 提醒到期时显示系统通知和响铃窗口；提醒、分组、标签及提醒历史保存在本地 SQLite，并支持历史筛选与分页。
- ✨️ 支持每日自动备份并保留最近 7 份备份，托盘菜单可快速创建 10 或 30 分钟倒计时。
- 🐛 修正重复提醒的月底与 31 号规则，并改善响铃窗口关闭时对并行提醒的处理。
- 🎨 改进提醒表单、列表、设置和分组/标签管理界面。

这是预览版本。首次使用或升级前，请先从“设置 → 备份”导出重要数据；遇到问题请通过 GitHub Issues 反馈。
