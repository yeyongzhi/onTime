# 常见问题

## 需要账号或联网吗？

无需注册账号，本地提醒和数据管理可以离线使用。更新节假日日历、检查版本和下载安装包需要联网。

## 关机、睡眠或退出后还会响吗？

不会，应用也不会主动唤醒电脑。恢复或重新启动后，会补响最近 30 分钟内的漏响；更早的漏响只记录。

## 关闭窗口等于退出吗？

关闭主窗口会收起到托盘。要停止应用，请从托盘菜单选择“退出（停止提醒）”。

## 为什么节假日安排不准确？

请在“设置 → 数据”检查当年日历并更新。缺少当年日历时，应用按普通星期规则计算，并显示提示。

## 可以同步到其他电脑吗？

目前没有内置云同步。可以通过导出备份，在另一台电脑恢复；恢复会覆盖目标应用的当前数据。

## 数据在哪里？

在首次运行时选择的本地目录中，具体路径可在“设置 → 数据”查看。备份和升级前请保留该目录。

## 没找到安装包怎么办？

请以 [Releases](https://github.com/yeyongzhi/onTime/releases) 为准。开发分支的自动构建产物保存在 GitHub Actions 中，不代表已经发布稳定版。
