# 常见问题

## 需要账号或联网吗？

无需注册账号，本地提醒和数据管理可以离线使用。检查版本和下载安装包需要联网。

## 关机、睡眠或退出后还会响吗？

不会，应用也不会主动唤醒电脑。请让 onTime 保持在系统托盘运行；可以在“设置 → 常规”开启登录时启动。恢复或重新启动后，会补响最近 30 分钟内的漏响；更早的漏响会发送系统摘要，并在“我的提醒”页显示最近的过期提醒。历史默认永久保留，也可以设置保留天数。“提醒历史”菜单可查看保留的处理记录，可按名称、状态和时间范围筛选并分页查看。

## 为什么没有看到系统通知横幅？

请在“设置 → 常规”确认通知权限，并发送测试通知。Windows 专注助手、macOS 专注模式或勿扰设置可能隐藏横幅；提醒触发时应用仍会打开响铃窗口。测试通知只验证通知发送链路，不代表应用退出后仍能提醒。

## 关闭窗口等于退出吗？

关闭主窗口会收起到托盘。要停止应用，请从托盘菜单选择“退出（停止提醒）”。

## 可以同步到其他电脑吗？

目前没有内置云同步。可以通过导出备份，在另一台电脑恢复；恢复会覆盖目标应用的当前数据。

## 数据在哪里？

Windows 新安装默认在程序安装目录中，macOS 默认在系统用户数据目录中，已有自选目录继续沿用。具体路径可在“设置 → 数据”查看，并可直接打开本地目录。备份和升级前请保留该目录。

## 没找到安装包怎么办？

请以 [Releases](https://github.com/yeyongzhi/onTime/releases) 为准。开发分支的自动构建产物保存在 GitHub Actions 中，不代表已经发布稳定版。

## 为什么检查更新显示暂时受限？

GitHub 匿名 API 按出口 IP 限制请求频率，共用网络或代理的其他程序也可能消耗额度。beta5 优先使用官网静态清单，仅在官网不可用时有限度地尝试 API，并遵循服务端等待时间。请按提示稍后重试，或点击“前往发布页”。提醒与本地数据不受影响。

beta3 / beta4 仍使用旧更新源。遇到限流时，请先从 Releases 手动下载安装 beta5。
