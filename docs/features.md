# 为你的每一天留好提醒

## 时间安排，一眼看清

“我的提醒”显示下一次提醒、已启用数量和全部提醒。用网格浏览，用列表快速检查状态；搜索名称、按多个标签筛选，找到当前关心的安排。

新建提醒时，可以选择定点时间或倒计时。一次性安排用日期，每周固定事项用重复星期；工作日与周末安排结合中国大陆节假日和调休日历计算。

## 提醒方式，由你决定

内置轻铃适合日常使用，也可以导入自己的音频并试听。音量、音量渐强、自动停止时间与最多贪睡次数，都能按每个提醒单独设置。

提醒触发时提供独立窗口和系统通知；需要再等一会儿，可以贪睡 5 或 10 分钟。已处理的提醒会留下记录，方便回看。

## 多个提醒，一起管理

给提醒添加彩色标签，区分工作、生活与健康。进入“批量管理”后，勾选提醒或全选当前筛选结果，再启用、停用或删除；删除前会询问确认。

## 数据与外观，掌握在自己手里

数据保存在你选择的目录中。导出 ZIP 备份可以保存提醒、标签、记录、日历和铃声；恢复会覆盖当前数据，应用会保留恢复前备份。

主题支持亮色、暗色和跟随系统。选一个喜欢的颜色，调整字号、圆角与侧栏宽度；侧栏也可以收起，为提醒留出更多空间。
