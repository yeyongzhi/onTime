# 开始使用

## 下载与安装

前往 [下载页面](https://github.com/yeyongzhi/onTime/releases)，选择与你的系统匹配的安装包。Windows 使用 `.exe`，macOS 使用 `.dmg`；实际可用的版本以下载页面为准。

macOS 安装包目前未完成 Developer ID 签名和公证。安装时请遵循系统提示及组织设备管理要求。

## 选择数据目录

首次打开应用时，选择一个长期可用、可写的本地文件夹。提醒、铃声、配置与日历会保存在这里。不要选择受保护目录或 macOS 的应用包内部。

设置中的“数据”可以查看和切换目录。切换会打开目标目录的数据，不会自动迁移原目录；需要迁移时，先导出备份，再切换并恢复。

## 创建第一个提醒

点击“新建提醒”，填写名称，选择定点提醒或倒计时。设置时间与重复规则，按需选择铃声，打开“保存后启用”，最后保存。

一次性提醒完成后会自动停用。重新启用倒计时会重新开始计时。

## 让提醒持续运行

关闭主窗口后，应用仍在托盘运行。可从托盘重新打开或退出；也可在“设置 → 常规”开启登录自启动。退出应用会停止提醒。

## 备份你的安排

在“设置 → 备份”导出备份，妥善保存 ZIP 文件。恢复会替换当前数据并取消正在活动的提醒，操作前请确认所选文件。
