## 从一个小提醒开始

1. 下载并安装适合你电脑的 onTime。
2. 选择一个可写的本地数据目录。
3. 创建提醒，设置时间与铃声，然后启用。

应用支持 Windows 与 macOS 的安装包构建。可下载版本与平台请以 [Releases](https://github.com/yeyongzhi/onTime/releases) 中实际提供的文件为准。

提醒需要应用保持运行。关闭主窗口后会收起到托盘；退出应用、关机或睡眠期间不会响铃，也不会唤醒电脑。

想了解完整功能，可以查看[功能介绍](/features)、[开始使用](/guide)与[更新日志](/changelog)。
